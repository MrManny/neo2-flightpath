"neo2-flightpath": minor

Add the neo2-flightpath desktop app (Electron): pick a recording and watch its flight path on the map in sync with the footage, with one shared timeline scrubber and a swappable picture-in-picture layout. The `--trail` option is removed (config files must drop the `trail` key): the incremental trail update over an up-front decimated track is now the only strategy.
